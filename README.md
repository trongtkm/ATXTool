# ATXTool — kênh cập nhật cũ (chỉ để chuyển sang SWITool)

Repo này **chỉ** là kênh cập nhật cũ của add-in iTool/ATXTool cho SolidWorks. Máy còn cài iTool cũ đọc
`version.json` ở đây và được mời cài **SWITool**. Sau khi cài, SWITool tự nhận cập nhật từ
[trongtkm/updates](https://github.com/trongtkm/updates) (`switool/version.json`).

Không phát hành bản iTool mới ở đây. Bộ cài trong Releases là đúng file đã phát hành trên trongtkm/updates.
